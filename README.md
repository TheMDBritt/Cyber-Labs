# Cyber-Labs

Hands-on home lab work across identity, endpoint, and detection scenarios. Each lab is a self-contained exercise: objective, build steps, observed results, and what I'd change in a production environment.

---

## Lab Areas

- **Active Directory:** domain build-out (`cyberlab.local`), OU strategy, security group design, GPO authoring
- **Windows Administration:** Computer Management workflows (Task Scheduler, Event Viewer, Shared Folders, Performance, Device Manager) for posture and triage
- **Linux:** configuration, hardening, authentication log analysis
- **Endpoint and EDR:** posture monitoring, anomaly investigation
- **Log Analysis and Detection:** SIEM workflows, detection logic, alert tuning
- **Vulnerability Management:** scanning and triage workflows

---

## Tooling

Windows Server, Active Directory, Group Policy, Kali Linux, Wireshark, common SIEM and EDR platforms, scripting in PowerShell and Python.
